# GHM Atlas Command Centre v31+ RC3.4 Composition Corrections

**Release date:** 29 July 2026  
**Source build:** v31+ RC3.3 Chrome Pass  
**Data snapshot:** 21 July 2026 (unchanged)

## Main changes

- Rebuilt Overview spacing, background and hero treatment to use the same composition system as Territory pages.
- Replaced Overview and Territory Waffle previews with compact Block previews.
- Added the standard compact progress gauge beneath the Overview Command Centre icon.
- Replaced all rainbow progress bars with a dark track and one bright status colour.
- Standardised In progress to turquoise, Critical to `#ff1744`, High/At risk to bright orange, Review to blue and Complete to green.
- Separated the Overview current-status heading from the status-card field.
- Reframed the Overview Bird’s-eye preview so the complete programme is visible.
- Changed Quick Chamber Evidence to a two-column desktop layout with a one-column phone fallback.
- Tightened Territory hero spacing between the main icon and information.
- Removed Bird’s-eye node glow and introduced a crisp expanding ring pulse.
- Doubled Bird’s-eye Territory illustration sizes and kept backing circles removed.
- Made the previous Waffle hover stroke treatment the permanent card treatment.

## Data and privacy

No live Google Sheets connection was added. The approved embedded snapshot and record counts are unchanged. Estimated percentages remain non-authoritative visual placeholders and are labelled `est.`.

## Outstanding asset

The replacement primary Territory/navigation icon set remains pending and can be inserted in an asset-only pass.
