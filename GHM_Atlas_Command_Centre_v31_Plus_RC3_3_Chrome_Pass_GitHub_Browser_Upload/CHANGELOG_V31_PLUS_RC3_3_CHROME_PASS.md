## Main changes

- Rebuilt the Overview composition around the approved Territory-page visual language and the supplied 29 July homepage mock-up.
- Added the supplied corrected Command Centre Map artwork to the loader, Overview hero and Bird’s-eye centre.
- Standardised temporary progress presentation as compact `% est.` values with a shared multicolour gradient gauge.
- Reworked the Overview Territory summary, Waffle wall, Bird’s-eye preview, action panels, condensed Territory list, audit indicator and selected-Territory register.
- Lightened Bird’s-eye artwork, strengthened node pulses, doubled node dots, removed icon backing circles and kept relationship paths animated.
- Preserved genuine **At risk** risk states while relabelling active delivery seals as **In progress**.
- Restored full-strength status colours across operational registers.
- Replaced Milestone corner status blocks with wax seals and improved the live Milestone record action.
- Improved Quick Chamber headings, evidence rows, blocked-state treatment and responsive information layout.
- Corrected the 1440px navigation collision by keeping the five primary visual views visible and moving secondary links into the existing slide-in menu.
- Added route scroll restoration safeguards to prevent the Overview and Territory artwork being clipped after navigation.
- Improved tablet/mobile menu alignment, summary grids, record actions, back-link spacing and Territory progress visibility.
- Prevented the Waffle/Block tooltip layer from remaining visible after a Quick Chamber opens or closes.
