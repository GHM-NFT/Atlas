This folder is the derived browser-hosted review edition. It contains the same approved 21 July 2026 embedded snapshot and RC3.8 runtime as the Internal Local Mac build.

## Upload

1. Extract this ZIP.
2. Upload the complete extracted folder to the repository root.
3. Commit all files to the branch used by GitHub Pages.
4. Keep the folder name unchanged:

`GHM_Atlas_Command_Centre_v31_Plus_RC3_8_GitHub_Browser_Upload`

5. Review at:

`https://ghm-nft.github.io/Atlas/GHM_Atlas_Command_Centre_v31_Plus_RC3_8_GitHub_Browser_Upload/index.html`

GitHub Pages may take several minutes to publish after the commit.
