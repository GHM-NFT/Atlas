# GHM Atlas Command Centre v31+ RC3.7 — GitHub browser upload

This folder is the browser-hosted review edition. It contains the same approved 21 July 2026 embedded snapshot as the local Mac build.

## Upload

1. Extract this ZIP.
2. Upload the complete extracted folder to the repository root.
3. Commit all files to the branch used by GitHub Pages.
4. Keep the folder name unchanged:

`GHM_Atlas_Command_Centre_v31_Plus_RC3_7_Final_Amends_GitHub_Browser_Upload`

5. Open:

`https://ghm-nft.github.io/Atlas/GHM_Atlas_Command_Centre_v31_Plus_RC3_7_Final_Amends_GitHub_Browser_Upload/index.html`

GitHub Pages may take several minutes to publish after the commit.

## Important

- This edition has no live Google Sheets connection.
- The dataset is embedded in `js/data.js`.
- Do not upload this edition to a public repository unless the embedded programme data is approved for public access.
- CSS is combined into `css/atlas-combined.css` to keep the browser-upload file count below GitHub’s 100-file limit.
