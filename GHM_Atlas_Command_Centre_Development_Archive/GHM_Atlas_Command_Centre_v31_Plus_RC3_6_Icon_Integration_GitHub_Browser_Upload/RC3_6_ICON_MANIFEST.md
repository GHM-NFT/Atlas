# RC3.6 Supplied Icon Integration Manifest

All artwork in this manifest was supplied by the project owner. No image generation was used.

The production site uses **512 × 512 lossless WebP files with transparency**. This is sufficient for the largest current interface placement at high-density display scale while reducing browser download size. Each source canvas was first normalised to 1024 × 1024 without cropping, then reduced with high-quality Lanczos resampling.
