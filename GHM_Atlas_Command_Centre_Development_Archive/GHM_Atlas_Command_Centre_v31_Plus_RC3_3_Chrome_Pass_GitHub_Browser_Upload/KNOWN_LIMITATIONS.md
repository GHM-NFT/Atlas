# Known limitations — RC3.3

- The replacement primary Territory/navigation icon set is still being prepared. Existing icons remain in place.
- Progress percentages are visual estimates only because the approved snapshot has no authoritative completion-percentage field. They are labelled `est.` and must be replaced when the next approved snapshot supplies a canonical value.
- The build is snapshot-based and does not update live from Google Sheets.
- Google-hosted Roboto Slab and Inter require an internet connection; local serif/sans-serif fallbacks are used when unavailable.
- The Bird’s-eye layout is intentionally information-dense and is best reviewed on desktop. Touch pan/zoom and compact controls remain available on tablet and phone.
- Final visual acceptance requires a fresh Chrome pass on the agreed viewport sizes.
