# GHM Atlas Command Centre v31+ RC3 Visual Amendments — GitHub Browser Upload

Upload the **contents of this folder** to the repository folder or root used by GitHub Pages.

## GitHub Pages
1. Open the repository **Settings → Pages**.
2. Select **Deploy from a branch**.
3. Select `main` and `/ (root)`.
4. Save and wait for the deployment to finish.

The approved 21 July 2026 dataset is embedded in `js/data.js`. This is a snapshot, not a live Google Sheets connection.

## Data warning
GitHub Pages is public. Anyone with the URL can inspect the site files and embedded snapshot. Use only where that exposure is approved.

## Review sizes
